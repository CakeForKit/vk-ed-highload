# Расчётно-пояснительная записка для курсовой работы по предмету «Проектирование высоконагруженных систем»

## 1. Тема и целевая аудитория

**Тип сервиса:** видеоплатформа (аналог VK Видео).

### Основной функционал MVP:

- Регистрация и авторизация пользователей;
- Публикация видео;
- Просмотр видео;
- Поиск видео и авторов;
- Подписка на авторов;
- Реакции;
- Лента рекомендаций;

### Ключевые продуктовые решения:

- Видео можно смотреть без регистрации;
- Рекомендательная система анализирует содержание видео и подбирает контент под пользователя;

### Ключевые функции, характеризующие сервис:

- Просмотр и загрузка видеоконтента;
- Персональная рекомендация видео;
- Подписки, комментарии, реакции.
