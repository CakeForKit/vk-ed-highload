### Рассчеты:
Среднее количество видео, публикуемых одним автором в месяц: 4,16 млн / 331 тыс. = **~12,6 видео в месяц на одного автора.**

Средний вес одного загруженного видео: 14,8 мин * 50 МБ/мин = **~740 МБ на одно видео.**

Средний размер хранилища на одного автора за год: 12,6 видео/мес * 12 мес × 740 МБ = **~111,9 ГБ в год.**

### RPS по типам запросов

```
Средний RPS = (Количество действий за сутки) / 86 400 секунд в сутках
Пиковый RPS = Средний RPS * Коэффициент пиковости (2,5–3)
```

| Метод / Тип запроса | Формула среднего RPS                  | Комментарий                                                                                                    | Средний RPS   | Пиковый RPS (2,5–3)   |
