### Процнтное соотношение видео разного качества
| Качество        | Вес 1 минуты (технология сжатия AV1)     | Процент от количества видео (шт.) | Условная доля в хранилище (для одинаковой длительности видео) |

| 480p (SD)       | ~7 МБ                                    | 20%                               | ~10%                                                          |

#### Формулы:
Условная доля в хранилище = ((Процент от количества видео шт.) * (Вес 1 минуты)) / СУММА((Процент от количества видео шт.) * (Вес 1 минуты)) * 100%

Объём N видео = N * (0.05 * 50 + 0.45 * 15 + 0.30 * 11 + 0.20 * 7) МБ * ~14,8 минут (средняя длительность одного видео)

## 2.2 Технические метрики


### RPS по типам запросов

```
Средний RPS = (Количество действий пользователя за сутки) / 86 400 секунд в сутках 
Пиковый RPS = Средний RPS * Коэффициент пиковости (3)
```

| Метод / Тип запроса | Формула среднего RPS            | Комментарий                                                          | Средний RPS | Пиковый RPS (3) |
|:--------------------|:--------------------------------|:---------------------------------------------------------------------|:------------|:----------------|
| Просмотр видео      | (42,2 млн * 99,1 / 1440  ) / 60 | DAU * (среднесуточное время просмотра / 1440 мин в сутках)           | ~48 403     | ~145 209        |
| API — публикация    | 110 тыс / 86 400                | Загрузок в месяц / 30 дней = 3,310 млн / 30 = 110 тыс загрузок/сутки | ~1,2        | ~3,6            |
| API — реакции       | 4400 / 86 400                   | Лайков в месяц / 30 дней  = 132 тыс / 30 = 4400                      | ~0.05       | ~0,12           |
| API — комментарии   | 500 / 86 400                    | Комментариев в месяц / 30 дней  = 15 тыс / 30 = 500                  | ~0.005      | ~0,017          |
